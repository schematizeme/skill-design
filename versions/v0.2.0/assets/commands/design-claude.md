Crie (ou **mescle**, preservando o que já existe) o `CLAUDE.md` na raiz do repo com os pisos de design da casa, a
partir de `.claude/skills/schematize-design/assets/CLAUDE.md` (ou `~/.claude/skills/schematize-design/assets/CLAUDE.md`).

Regras da mesclagem: **não apague** regra existente; acrescente a seção de design; se já houver uma, **atualize-a** e
diga o que mudou. O `CLAUDE.md` é sempre-on: vale para toda sessão neste repo, sem ninguém precisar carregar a skill.
